# Employee Record System

Sistem i thjeshtë regjistrimi punonjësish (SHTO / FSHIJ / KËRKO) me fushat: emri, mbiemri, departamenti dhe pozicioni. Demoja web është simulim funksional i aplikacionit origjinal desktop — të dhënat fillestare vijnë nga `sample.xlsx` dhe ruhen në localStorage të browserit.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

## 📁 Struktura
- `index.html`
- `demo/index.html`
- `original/ers.py`
- `original/sample.xlsx`
- `README.md`
- `PROVENANCE_LICENSE.txt`
- `TREE`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python 3 + tkinter + openpyxl + xlrd + pandas:

```
pip install openpyxl xlrd pandas
python ers.py
```
